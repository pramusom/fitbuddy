# fitbuddy# FitBuddy - Your Personal Fitness Companion

FitBuddy is a simple Python application built as part of the TNSDC project. It helps users track their fitness journey by logging workouts, water intake, and meals.

### Features
- 🏋️ Log workouts with duration and calories burned
- 💧 Track daily water intake
- 🍎 Log meals and calorie intake
- 🎯 Get personalized workout suggestions (Weight Loss, Muscle Gain, Fitness)
- 📊 View daily summary report

### How to Run
1. Clone the repository
2. Run `python main.py`
3. Follow the menu instructions

### Tech Stack
- Python 3
- GitHub for version control
